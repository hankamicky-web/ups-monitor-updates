# UPS Monitor Updates

Public update channel for UPS Monitor ESP32-S3 devices.

This repository contains distribution files only.

## Public files may include

- Signed firmware binaries
- Firmware update manifests
- UPS compatibility profile libraries
- Signed UPS profile packages
- Release information

## Source Code

Source code is NOT published in this repository.

## Security

Private signing keys, licensing keys, credentials and development tools are never stored here.
